# DummyJSON на Alpine.js

Описание приложения: после нажатия на «Список пользователей» браузер получает данные из внешнего API и добавляет их на страницу без перезагрузки.

## Как это работает

1. Alpine.js создаёт локальное состояние компонента: `users`, `loading` и `error`.
2. Обработчик `@click="loadUsers"` вызывает `fetch()` для адреса `https://dummyjson.com/users/`.
3. Параметры `limit=5` и `select=firstName,lastName,email` уменьшают ответ до пяти пользователей и только нужных полей.
4. После преобразования ответа из JSON массив попадает в `users`.
5. Директива `x-for` создаёт строку списка для каждого пользователя. `x-show` переключает начальное сообщение, загрузку, ошибку и результат.

Повторный клик выполняет новый запрос и заменяет список актуальным ответом API. Во время запроса кнопка недоступна, а ошибки сети или HTTP показываются пользователю.

## Почему выбран Alpine.js

DummyJSON возвращает JSON. Чистый htmx не предназначен для шаблонизации JSON в браузере: понадобился бы собственный сервер-посредник или дополнительная библиотека.

Alpine.js подходит:
- умеет хранить данные и декларативно отображать их прямо в HTML;
- позволяет выполнить `fetch()` без отдельной системы сборки;
- компактнее полноценного SPA-фреймворка для одной интерактивной страницы;
- приложение остаётся полностью статическим и может работать на GitHub Pages.

Итого используется сочетание нативного Fetch API для получения данных и Alpine.js для состояния и отображения. htmx намеренно не добавлен: в этой задаче он не упрощает обработку JSON.
