# DummyJSON на htmx и Handlebars

После нажатия на «Список пользователей» приложение получает данные из внешнего API и добавляет их на страницу без перезагрузки и без написанного вручную JavaScript-кода.

## Как это работает

1. Атрибут `hx-get` библиотеки htmx отправляет GET-запрос к `https://dummyjson.com/users/`.
2. Параметры `limit=5` и `select=firstName,lastName,email` ограничивают ответ пятью пользователями и нужными полями.
3. Расширение htmx `client-side-templates` передаёт полученный JSON шаблонизатору Handlebars.
4. Handlebars выполняет цикл `{{#each users}}` и формирует HTML-список.
5. htmx вставляет результат в элемент `#users`, не перезагружая страницу.

Во время запроса htmx показывает индикатор загрузки и блокирует кнопку. Повторное нажатие выполняет новый запрос и заменяет список актуальным ответом API.

## Почему выбрано это сочетание

- **htmx** описывает сетевой запрос и обновление страницы декларативными HTML-атрибутами.
- **Client-side Templates** позволяет htmx работать с JSON, хотя основной сценарий htmx рассчитан на готовые HTML-фрагменты.
- **Handlebars** безопасно преобразует JSON в HTML по декларативному шаблону.
- Приложение остаётся статическим: не нужны backend, npm и система сборки.

В проекте нет собственного JavaScript: подключены готовые библиотеки, поведение задано разметкой.
